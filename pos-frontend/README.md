# Sethos Store — Frontend

Angular 22 terminal and back office for Sethos Store. See the [project README](../README.md)
for setup, the API, and how the two halves fit together.

```bash
npm install     # first time only
npm start       # dev server on http://localhost:4200
npm run build   # production bundle in dist/sethos-store-frontend
```

The backend must be running on port 8080; the app loads store settings from it at startup.
